## 🚀 Project Overview & Features

* **Backend API (`FastAPI` / Python):** Handles core application routes, database queries, and data pipelines lankamart_project (1)/lankamart/backend/app/main.py, lankamart_project (1)/lankamart/backend/app/queries.py].
* **Frontend UI (`React` & `Vite`):** Fast, responsive, and modern web interface styled for optimal user experience lankamart_project (1)/lankamart/frontend/index.html].
* **Machine Learning & Analytics (`scikit-learn`):** Integrated intelligence modules for sales metrics, product recommendation, and predictive order processing lankamart_project (1)/lankamart/backend/app/ml.py, lankamart_project (1)/lankamart/backend/models/metrics.json].
* **Database Management (`SQLite`):** Lightweight, embedded relational database setup with automated seed schemas lankamart_project (1)/lankamart/database/lankamart.db, lankamart_project (1)/lankamart/database/schema.sql].
